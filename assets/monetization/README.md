# Pass and product icons

One 512 x 512 PNG per game pass and developer product, named after its `Key` in
`src/shared/Config/Monetization.luau`. Upload each when you create the matching
item in Creator Hub -> Monetization; the table in
[docs/LAUNCH.md](../../docs/LAUNCH.md) pairs every file with its item and price.

Generated by script, not by hand: a vertical gradient in the item's colour, a
white sunburst, the subject, and the item name in bold white with a dark
outline. Twelve use the emoji from the config as the subject; the four `Belt*`
icons draw an actual slime instead, since a plain coloured circle read as
nothing at tile size.

Keeping the set visually consistent matters more than any single icon — in the
shop UI they are seen as a row, and one mismatched icon makes the whole shop
look unfinished. If you replace one, match the gradient, the outline weight and
the label treatment of the others.
